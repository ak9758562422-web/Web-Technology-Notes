WEB TECHNOLOGY NOTES WEBSITE
============================

Files:
- index.html   Main website and home page
- style.css    Responsive design and visual styling
- script.js    Unit navigation and unit-wise notes

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or another modern browser.
3. Select any Unit card to open its notes.
4. Use the topic list at the left/top of the notes page to jump between topics.

The website works locally without a backend. An internet connection is only needed to load the optional Google Font; system fonts will be used otherwise.

Syllabus basis:
Web Technology (CS35302), CSE, 5th semester, Quantum School of Technology.
The five units and teaching hours follow the uploaded syllabus. The notes are explanatory study material and should be used alongside faculty-provided notes and references.
